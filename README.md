# NUTORY / 너토리

韓国向けの架空のピーナッツパウダーブランドLPです。韓国語原稿、CSS、JavaScript、AI生成画像をすべて `index.html` に埋め込んでいます。外部CDN、フォント、画像、パッケージのインストールやビルドは不要です。

## 閲覧

ダウンロードした `index.html` をブラウザで開けます。サーバーで開く場合は `STARTUP.md` を参照してください。file:// ではブラウザによってお気に入りの永続保存が制限されることがあります。その場合もページ内の状態を維持します。

## 内容

レシピ3種、商品3種、数量1〜10、商品小計30,000ウォン以上の送料無料、デモ注文ダイアログ、お気に入りの保存・一覧・削除、FAQ、モバイルメニュー、キーボード操作、動きを減らす設定に対応しています。コレクションは最後に選んだ1商品のみ保存する仕様で、キーは `nutory-collection-v1`、形式は `{"flavor":"original"}` です。

## 架空の設定について

実在の商品・販売事業者ではありません。価格・原料・製法・栄養数値は架空の設定であり、実製品の分析や認証によるものではありません。画像は今回の再構築で新規AI生成しました。実際の注文・決済・配送・個人情報の取得・アクセス解析は行いません。コレクションはブラウザ内のみで保存します。

FVをキャラメル色の広告写真へ変更。モバイル専用の縦長画像も含みます。青基調からクリーム・ローストブラウン・キャラメル・深緑の配色へ変更し、帯マーキーをFV内の大型背景タイポグラフィへ移しました。

承認された追加6構成：美味しさの接写、2つの味の比較、作り方3ステップ、朝昼夜の食べ方、アレンジレシピ集、初めての人向けガイド。新規AI生成画像は6点（PC広告、モバイル広告、クリーム接写、温かいラテ、作り方、デザート）です。写真の湯気に加えて、控えめな湯気・粉粒子の動きを実装し、prefers-reduced-motion時には動きを停止します。

Chromium/Playwrightで全画像のデコード、追加6セクション、味選択リンク、360/390/768/1440pxの横はみ出し、既存の商品・送料・保存・レシピ・ダイアログ機能、JavaScriptエラー0件を確認しました。サイトの公開・デプロイは行っていません。

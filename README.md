# NUTORY / 너토리

韓国向けの架空のピーナッツパウダーブランドLPです。韓国語原稿、CSS、JavaScript、画像を `index.html` に埋め込んでいます。外部CDN・フォント・画像への依存、パッケージのインストール、ビルドは不要です。

## 閲覧・ダウンロード

納品専用ブランチ `delivery/nutory-cm-20261112` の `delivery/NUTORY.zip` を保存して展開し、`index.html` をChromeなどのブラウザで開いてください。GitHubのファイル画面では **Download raw file**（↓）で取得できます。HTML単体はブランチのルートにもあります。サーバーでの閲覧手順は `STARTUP.md` に記載しています。file://ではブラウザによって永続保存が制限されることがあります。

`delivery/revision-preview.jpg` は今回修正した原料・夜のデザート・味比較・FAQの実画面です。

## 今回の修正

- 重複したCSSの豆キャラクターを削除し、ラベルの帽子と手袋のピーナッツに合わせたキャラクターを導入の1か所に配置。
- 原料の説明を、ローストした豆と細かいパウダーの専用写真へ変更。写真の輪郭には殻のくびれを使用。
- 21:00の夜のセクションへ、アイスとピーナッツソースの専用写真を追加。
- 味比較は各味の単独商品写真へ変更。ディープローストには緑の瓶だけを表示。SHOPも独立した物撮り写真を使用。
- 朝食とレシピの写真を分離し、デザインの異なる瓶を除去。レシピタブでは写真・説明・手順・代替テキストが切り替わる。
- PC/モバイルの広告写真の粉を、細かなパウダーの質感へ修正。
- ブランドメッセージをオレンジ、FAQを深緑の全面背景へ。薄い紙のノイズと境界をまたぐピーナッツ写真を追加。
- サンセリフ中心へ書体を整理。FAQを＋／−表示に変更。FVの背景文字をCTAから離し、レシピ近くに流れる帯を配置。
- 追従CTAはFV・SHOP・フッターでは非表示。架空ブランド等の注記は商品購入・栄養情報/FAQ・フッターの3つの情報群に集約。

## 機能・検証

レシピの左右/Home/Endキー、商品3種、数量1〜10、商品変更時の数量リセット、小計30,000ウォン以上の送料無料、デモ注文、コレクション保存・再読込・削除・保存不可時のページ内保持、ダイアログのEsc/背景クリック、FAQ、モバイルメニュー、prefers-reduced-motionに対応しています。保存キーは `nutory-collection-v1`、形式は `{"flavor":"original"}` などです。

Chromium/Playwrightで全14画像のデコード、料理写真の切替、360/390/768/1440pxの横はみ出しなし、主要操作、JavaScriptエラー0件を確認済みです。変更箇所のPC・スマホ画像も確認しています。

## 架空の設定について

実在の商品・販売事業者ではありません。価格・風味・原料・製法・保存・栄養数値は架空の設定であり、実製品の分析・認証結果ではありません。画像はAI生成です。実際の注文・決済・配送・個人情報取得・アクセス解析は行いません。コレクションはブラウザ内だけで保存します。

旧環境の完成物は取得できず、引き継ぎ仕様から再構築したものを改修しています。制作前のcocori HTMLは `/tmp/nutory/previous-index.html` に退避済みです（ZIPには含めません）。納品専用ブランチを利用し、`main` と `.github/workflows/pages.yml` は変更せず、サイトのデプロイは行いません。

# 파도불 — 입안에, 불맛의 파도.

韓国向けの架空の直火チュクミブランド「파도불」のLPです。参考画像の食品広告表現をもとに、濃紺・コバルトブルー・赤で構成しました。

HTML・CSS・JavaScript・生成した料理画像・SVGキャラクターを `index.html` に内包しています。外部フォントやライブラリへの通信、ビルド、依存パッケージのインストールは不要です。

## 閲覧・編集

`index.html` をブラウザで開くか、リポジトリ内で以下を実行します。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## 実装

- 韓国語のブランドストーリー、箸上げ・食感・ソース・直火・辛さ比較・食べ合わせ・コース・調理・保管・商品・FAQ
- 生成した料理写真とオリジナルSVGキャラクター「불꾸」、CSSによる架空のパッケージ
- 商品とソースが弾ける新規生成FV、背景の巨大な流動タイポグラフィ、登場アニメーションの再生ボタン
- 湯気・火の粉、ポインターに反応するFV、材料がスクロールで集まる演出、浮遊・回転・ホバー演出
- キーボードでも切り替えられる4種のレシピタブ、食べ方カードからの連動、辛さ比較と商品選択の双方向同期、数量・送料計算、デモ注文
- コレクション保存（ブラウザのlocalStorage）、スマートフォン用ナビ・購入導線
- 動きを減らす設定、ダイアログのキーボード操作に対応

商品・価格・人物・レビュー・配送条件は架空です。写真はAI生成のイメージです。実際の注文・決済・発送・個人情報収集は行いません。コレクションは現在のブラウザ内だけに保存され、外部サービスへの追加や端末間同期は行いません。

## 検証

追加後は17箇所の画像表示、外部リソースへの通信がないこと、通常・動きを減らす設定での表示、登場演出の再生、材料集合演出、辛さ比較と商品選択の同期、3つの食べ方リンクも確認しています。

Chromium / Playwrightで全画像の読み込み、レシピ切り替え（クリック・方向キー）、保存状態の再読み込み、辛さ選択、注文合計・送料無料・数量上限下限・完了画面、ダイアログ、FAQ、モバイルナビを確認。375 / 390 / 768 / 1024 / 1440pxで横はみ出しがないことを確認しました。
